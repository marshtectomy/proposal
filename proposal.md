# Motivational Toadie

## Repository
<https://github.com/marshtectomy/proposal.git>

## Description
Artists often struggle with burnout and struggle to find the energy to finish their work. Motivational Toadie is a small toad designed to give random inspirational quotes to help boost morale and motivate artists get out of the slump and complete their task.

## Features
- Motivational Toadie can interact with the user through a friendly greeting and prompt a question for a need.
	- It will be executed by loading a text prompt "Hello fellow Artist! Are you in need of motivation?" as a start prompt.
- Motviational Toadie will generate a random inspirational quote for artists depending on a user's response
	- If a user answers "yes" then Motivational Toadie will prompt a charming quote at random, if a user answers "no" toadie will part with the user and say "Well alright, goodbye!" and end the program.
- Motivational Toadie will prompt by asking the user if it was successful in its task.
	- After the quote generated, the toad will prompt "Was I able to motivate you? :3" and depending on the user's answer of "yes" or "no" toadie will either reply with another inspirational quote or end the program with the farewell text above.
